# Figure assets

The retained PNG files are the original game item illustrations supplied with
the client snapshot, plus the large-ammo render described below. Only the 20
assets required by the current result figure are retained. Their game paths
are recorded in `data/catalog.json`. The figure uses these local files and
does not download images. Unused icons and duplicate vector files were removed.

The large-caliber Gold1 Soft-Nosed illustration was obtained separately from
[the original SVG](https://mafiareborn.com/assets/img/item/consumable/soft_nosed_bullet_large_2.svg).
Its source is retained as `evidence/soft_nosed_bullet_large_2.svg`; its PNG render
is `assets/png/consumable_soft_nosed_bullet_large_2.png`.

The large-caliber item is never illustrated with the small-caliber icon.
